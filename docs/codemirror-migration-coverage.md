# CodeMirror 6 migration coverage

[PR #22](https://github.com/narumiruna/gpui-editor/pull/22) (`e3d3788`) moved the text buffer, selections, edit transactions, and undo history into [`crates/codemirror`](../crates/codemirror/README.md). GPUI still owns the native editing surface. Hosts can create an editor with trusted native extensions through [`Editor::with_native_extensions`](../crates/app/src/editor.rs). The constructor keeps the stock extensions and source bytes. The core crate does not use GPUI, JavaScript, or a browser. This is a partial Rust port, not a drop-in replacement for CodeMirror 6.

No file migration is necessary. The editor uses the existing save path and keeps Markdown bytes outside the final replacement range unchanged. Input method composition now forms one undo step. Undo and redo store changed text instead of whole-document snapshots.
