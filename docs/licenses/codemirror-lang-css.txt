Port and oracle

The Rust parser uses the published v14 tables, specialization tables, scanner
hooks, and style tags from @lezer/css. A CSS scanner reads the local comment
token group. The shared Rust LR runtime does not split stacks or rank GLR
branches. The CSS fallback finds rule and declaration boundaries, uses the
published tables for separate headers and value suffixes, and recovers
incomplete syntax with a local parser. It does not reproduce every Lezer
error node or provide CodeMirror CSS completion.

The oracle generator uses the package versions and SRI values listed above
and these existing pins in docs/codemirror-upstream.json:
  @codemirror/autocomplete 6.20.4
  @codemirror/language 6.13.1
  @codemirror/state 6.7.6
  @lezer/common 1.5.7
  @lezer/highlight 1.2.5
  @lezer/lr 1.4.13
